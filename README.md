# XAUUSD Technical Analysis App
Aplikace pro real-time technickou analýzu zlata (XAU/USD).

## Funkce
- **Multi-timeframe analýza:** Trend na H1, vstupy na M15.
- **Indikátory:** EMA (20, 50, 200), RSI, MACD, Volume.
- **SMC prvky:** Detekce Order Blocků.
- **Risk Management:** Automatický výpočet SL a TP pomocí ATR.

## Požadavky
- Python 3.x
- MetaTrader 5 terminál
- Knihovny: `pip install MetaTrader5 pandas pandas_ta`
